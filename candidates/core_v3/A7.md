**Finite causes form an infinite chain** *(axiom, model, id: A7)*.

**Why this follows.** *Every event is caused* (A5) says each event has a cause. The next causality variant is the infinite chain of finite causes (E1P28 pattern): no first finite pusher inside the finite order.

**Axiom.** Every singular finite thing that is determined to exist and to act is so determined by another singular finite cause, which is itself determined by another, and so on to infinity in the order of finite causes (E1P28 pattern).

**Stated sense.** There is no first finite cause that starts the chain from inside the finite order. This does not deny Nature as free cause in the strict sense; it denies a first finite pusher.

**What would lower it.** Evidence of a finite first cause that itself has no finite cause while still being finite.

**Cap.** Cites A5. Effective confidence = min(own score, A5) once scored. D-mode is a definition and adds nothing.
