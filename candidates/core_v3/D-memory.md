**Memory** *(definition, id: D-memory)*.

**Why this follows.** Imagination needs memory; D-work already has a memory work at organization level.

**Definition 32 (memory).** *Memory* is the linkage of images of things with one another and with words, so that the mind passes from one to another (E2P18 Scholium pattern).

**Two uses.** (1) Psychological memory as above. (2) The memory work in *Work, and the seven works* (D-work). They rhyme; they are not the same definition.

**Limit.** Definition. Adds no confidence.

**References.**
- Spinoza, B. *Ethics*: E2P18 Scholium.
