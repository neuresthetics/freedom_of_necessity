## V011 · `A5` — Every event is caused

**Kind:** model · **Confidence:** pending (collider) · **Cap:** own score
**Rests on:** `D-exist`
**Supports (sample):** `D-free`, `P3`, `P4`, `P5`

**Claim (entry).** Every event is caused, a choice included.

**Dependency analysis.** Model axiom. Rests on D-exist (event as happening). Cap = own score. Supports D-free, P3, P4, P5, necessity_freedom expansion. Weaker than Spinoza E1P29 (no full necessitarianism of divine nature required). Uncaused choice-scale events would lower it; leftover would be chance, not freedom.

**Verse.**
A5: no uncaused events at the scale that includes choices. Cause = prior conditions from which the event follows (ordinary E1A3 sense). Does not say the cause is known, adequate (E3D1), or first-personal. Microphysical indeterminacy that never yields an uncaused choice does not lower A5; if it does, A5 falls and chance remains — which is not degree-freedom (D-free, P3).

**References.** Spinoza E1A3, E2P48 (report); contrast E1P29 (stronger; not required).
