**Claim (entry).** A work helps keep an organization going and is carried out by structures that organization produces or maintains; seven works named by test; "as one" by the take-apart test.

**Dependency analysis.** Definition. Rests on D-exist (activity going on). Supports D-whole, A3, A4, P1, P2, D-free, D-affect, and all work-F* expansions. Adds no confidence. Source pattern: Mossio, Saborido & Moreno 2009 (C1/C2).

**Verse.**
