**Proposition 2.** A collective mind happens in the society I live in. To the degree that the society performs control as one, with the signaling and memory that control uses, signals and stored information are combined into coordinated action there, as one process. This is an activity, not a thing, and not a claim that the society feels.

**What the name means.** By *collective mind* the book means control performed as one by a society, together with the signaling and memory that control uses (D-work, Definition 4). Nothing more is meant by the name.

**Demonstration.**

1. The society I live in performs control, signaling and memory as one, each at least in part (A4, rows control, signaling, memory).
2. Control is combining signals from the parts, and stored information, into changes that coordinate the parts (D-work, Definition 4). Performed as one, this combining is kept going by the society's own organization, not only by each member for themselves (D-work, Definition 3).
3. So at the society's level, signaling, memory and control are not three separate activities: control combines the other two into one coordinated activity. This is what the name picks out, so a collective mind happens in that society (by 1, 2 and the meaning of the name).
4. Since the name picks out the three works together, the collective mind happens to the degree of the lowest of their three grades, by the same rule as D-whole, Definition 6.
5. A work is an activity (D-work, Definition 1). So the collective mind exists as an activity exists: while it goes on. It is not a further thing the society has apart from that activity.
6. Nothing in A4, D-work or D-whole concerns a first-person description of the society's organization. So P2 says nothing about whether the society feels anything. ∎

**Cap.** P2 cites only A4, and within A4 only three rows, so it is no stronger than the weakest of the control, signaling and memory rows.

**Scholium 1 (why the word "mind").** In my own case, the third-person description of my mind's organization finds these same three works: a nervous system that combines signals and stored information into coordinated action (A2; A3, anchors). The name marks that likeness of works. It does not carry over A2's first-person clause.

**Scholium 2 (whether it feels: undecided).** Spencer (1860), the classic defender of the social organism, drew the line firmly: "the community as a whole has no corporate consciousness", and so "the State is to be maintained solely for the benefit of citizens." Spinoza's view would allow more: all individual things, "though in different degrees, are animated" (E2P13 Scholium), so on his terms, if a society is an individual, there is an idea of it too. The book adopts neither for the society, and P2 is scored without either. This is where A2's open question, why anything is felt, reaches the collective case, and it stays open there too.

**Scholium 3 (what changed).** The earlier P1 argued that since cells organized by type and function produce a person with a mind, persons organized the same way produce a collective mind. Under the new A2 that argument would carry the first-person clause across to the society and claim more than the evidence gives. P2 argues from A4's control, signaling and memory rows alone, and so claims only the activity.
