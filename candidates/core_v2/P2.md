**Proposition 2.** A collective mind, in the sense defined here, happens in the society I live in. To the degree that the society performs control as one, with the signaling and memory that control uses, signals and stored information are combined into coordinated action there, as one process. This is an activity, not a thing, and not a claim that the society feels.

**What the name means.** By *collective mind* the book means control performed as one by a society, together with the signaling and memory that control uses (D-work, Definition 6). Nothing more is meant by the name.

**Demonstration.**

1. The society I live in performs control, signaling and memory as one, each at least in part (A4, rows control, signaling, memory).
2. Control is combining signals from the parts, and stored information, into changes that coordinate the parts (D-work, Definition 6). Performed as one, this combining is carried out by structures (courts, offices, markets, records) that the society's own organization produces and maintains, not only by each member for themselves (D-work, Definitions 3 and 5).
3. So at the society's level, signaling, memory and control are not three separate activities: control combines the other two into one coordinated activity. This is what the name picks out, so a collective mind happens in that society (by 1, 2 and the meaning of the name).
4. Since the name picks out the three works together, the collective mind happens to the degree of the lowest of their three grades, by the same rule as D-whole, Definition 8.
5. A work is an activity (D-work, Definition 3). So the collective mind exists as an activity exists: while it goes on (D-exist). It is not a further thing the society has apart from that activity.
6. Nothing in A4, D-work or D-whole concerns a first-person description of the society's organization. So P2 says nothing about whether the society feels anything. ∎

**Cap.** P2 cites only A4, and within A4 it uses three rows, so it is no stronger than the weakest of the control, signaling and memory rows. Which society is meant ("the society I live in") is fixed by A4's membership clause, which cites A2, so P2 is also no stronger than A2. A2's clause (a) rests on cell theory, so this second cap is not expected to bind.

**Scholium 1 (why the word "mind").** In my own case, the third-person description of my mind's organization finds these same three works: a nervous system that combines signals and stored information into coordinated action (A2; A3, anchors). The name marks that likeness of works. It does not carry over A2's first-person clause.

**Scholium 2 (whether it feels: undecided).** Spencer (1860), the classic defender of the social organism, drew the line firmly: "the community as a whole has no corporate consciousness", and so "the State is to be maintained solely for the benefit of citizens." Spinoza's view would allow more: all individual things, "though in different degrees, are animated" (E2P13 Scholium), so on his terms, if a society is an individual, there is an idea of it too. The book adopts neither for the society, and P2 is scored without either. This is where A2's open question, why anything is felt, reaches the collective case, and it stays open there too.

**Scholium 3 (what changed).** The earlier P1 argued that since cells organized by type and function produce a person with a mind, persons organized the same way produce a collective mind. Under the new A2 that argument would carry the first-person clause across to the society and claim more than the evidence gives. P2 argues from A4's control, signaling and memory rows alone, and so claims only the activity.

**Scholium 4 (three senses of "mind").** The word can mean three things, and P2 claims only the first.

- *Control, in the book's sense*: combining signals and stored information into coordinated action, performed as one. P2 claims this, from A4.
- *Something felt*: a first-person side, something it is like to be the society. P2 does not claim this (Scholium 2).
- *Spinoza's sense*: the idea of a body, so that a society's mind would be the idea of the society (E2P13). That holds only if a society is an individual in his sense, which the core does not decide.

A familiar word given a new descriptive meaning can keep the force of the old one. Stevenson (1938) called this a persuasive definition. "In the sense defined here" is in the statement to stop that. An earlier statement read "A collective mind happens in the society I live in", and a reader could hear the second or third sense in it. Whether the name should change is an open question (README, section 5).
